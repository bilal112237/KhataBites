How to Deploy KhataBites on Vercel for Free

Step 1: Download Your App Code (`index.html`)

Click the button on the right to save the complete source code directly to your laptop or phone.

Step 2: Put It Online on Vercel (Takes 2 Minutes, Rs. 0 Cost)

  1. Create a free account on github.com and create a new repository named khatabites.
  2. Upload the index.html file (or the khatabites-vercel-deploy.zip files) into that GitHub repository.
  3. Go to vercel.com, click Sign Up with GitHub (free Hobby plan - no credit card required).
  4. Click Add New Project -> Import `khatabites` -> Deploy. Vercel will give you a live link like https://khatabites.vercel.app to share in your hostel WhatsApp group!

Step 3: Connect Real Cloud Database (Supabase PostgreSQL - Free)

Local Mode

This app already has the Supabase Cloud Client (`@supabase/supabase-js`) built in! Run the SQL below once in your free supabase.com project, then paste your Project URL & Anon Key below (or inside index.html):

create table if not exists public.khata_cloud_store (
  room_key text primary key,
  payload jsonb not null,
  updated_at timestamptz default now()
);
alter table public.khata_cloud_store enable row level security;
create policy "Allow public squad sync" on public.khata_cloud_store for all using (true) with check (true);
Saved!
